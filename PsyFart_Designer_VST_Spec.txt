# F4RT - PsyFart Designer VST

Product Name: F4RT 
Framework: JUCE
Targets: VST3, Standalone
Language: C++

## Goal
Create a dedicated psytrance sound-design instrument focused on generating synthetic "psytrance fart" sounds, squelches, burps, zaps, croaks, FM stabs, growls, formant hits, and transition effects.

The plugin should allow both instant preset generation and deep editing.

## Core Concept
A single MIDI note triggers a highly controllable synthesized transient sound.
Users should be able to design anything from:

- Classic Goa/Psy resonant farts
- Full-on formant stabs
- Forest psy croaks
- Darkpsy chirps
- Hi-tech laser burps
- Neuro-inspired growls
- Experimental alien vocal effects

## Fart Designer Macro Layer

High-level controls:

### Fart Size
Controls overall weight and duration.

### Wetness
Controls resonance and formant intensity.

### Anger
Adds FM complexity and distortion.

### Alienness
Introduces random formant movement.

### Squelch
Boosts resonant filter character.

### Rip Length
Controls tail length.

### Toxicity
Adds chaos modulation and nonlinear filtering.
