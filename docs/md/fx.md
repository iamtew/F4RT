# FX

![FX](fx.png)

Enable buttons: EQ, Comp, Delay, Reverb, Chorus, Phaser, Flanger, **Ring shift**, **Stutter**. Knobs do nothing while that effect is off, which keeps the rack from pretending it is doing work.

**Order** combos set the chain (left is first). Slots 8 and 9 are named **Shift** and **Grain**, because those are the two that needed nicknames.
