# Patches

![Patches](browser.png)

Two hundred factory seeds, then your saves. **Save As**, **Import**, **Fav**, and search / tags.

User files are `.f4rtp` in `%APPDATA%\Stupid Audio\F4RT\Patches`. Loading a factory patch starts from Init, so FX and matrix settings from the previous patch are cleared. That is on purpose: a seed is a seed, not a collage of whatever you were doing five minutes ago.
