# Motion

![Motion](motion.png)

Six envelopes, four LFOs. The envelopes are Pitch, Filter, FM, Vowel, Grit, and Loudness, each with Attack / Decay / Sustain / Release. The LFOs have Shape, Rate, Amount, and **Sync**.

Loudness sustain near zero is a one-shot toot. The plugin even says so, quietly: “sustain near 0 = one-shot”. Park it up and you get a normal held note, which is allowed, if a little less on-theme.
