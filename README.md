# F4RT

**F4RT** (PsyFart Designer) is a MIDI instrument for synthetic psytrance farts, squelches, croaks, zaps, and formant hits. Four oscillators, FM, formants, macros, randomizer, factory bank, FX rack.

VST3 and standalone. Stupid Systems LLC. [MIT](LICENSE). Site: [docs/](docs/index.html). Manual: [docs/MANUAL.md](docs/MANUAL.md).

## Release

`just build-dist` writes `dist/F4RT-<version>-win-x64-vst3.zip`, `dist/F4RT-<version>-win-x64-standalone.zip`, and `dist/F4RT-<version>-win-x64.msi`. Building the MSI needs the .NET 8 SDK.
